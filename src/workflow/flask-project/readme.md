#  Construímos um sistema full-stack completo e moderno!

- Backend: Uma API RESTful robusta com Flask e SQLAlchemy.

- Frontend: Uma UI reativa e elegante com Reflex, que consome a API em tempo real.

- Inovação: Um pipeline de dados com Prefect que automatiza a carga de dados de múltiplas fontes, demonstrando um caso de uso real de orquestração.

- Qualidade: Testes que garantem a estabilidade da API e logging para monitoramento.

- Padrões: Usamos conceitos de POO, MVC (adaptado para API/Reflex) e código limpo.
