# Tutorial de como usar o framework
---

## Método 1 (Execute esse comando no seu terminal) :

```bash
git clone https://github.com/PedroVic12/Repopulation-With-Elite-Set
cd Repopulation-With-Elite-Set/src/DashboardApp

pwd

pip install -r requirements.txt
```

Depois disso, todas as bibliotecas foram importadas e execute o comando

```py
streamlit run dashboard_rce_app_v9.py
```


## Método 2 (Forma Manual):

1) Entre no diretorio /src`

2) Execute para instalar as bibliotecas necessaria

```py
pip install -r requirements.txt
```

3) Execute o arquivo

```py
python run_framework_rce.py
```

Esse arquivo tem um executavel dentro da pasta build/run_rce_framework

4)  Para rodar o framework navegue ate:

Repopulation-With-Elite-Set/src/DashboardApp

E execute o frontend python

```py
streamlit run dashboard_rce_app_v9.py
```
