Plano de Estudos Full-Stack

Sua jornada interativa para dominar a arquitetura limpa com Flask, Astro e Flutter.

Nossa Bíblia: Princípios da Arquitetura

1. API como Fonte da Verdade

O backend Flask apenas entrega dados JSON. Ele não conhece o frontend, garantindo total desacoplamento.

2. Frontend "Burro"

Astro e Flutter são responsáveis apenas por exibir os dados de forma bonita. A lógica de negócio fica na API.

3. Contrato de Dados (JSON)

A comunicação é feita por um "contrato" JSON bem definido, garantindo que backend e frontend falem a mesma língua.

4. Um Serviço por Responsabilidade

No Flask, cada recurso (Blog, Loja, Financeiro) tem seu próprio arquivo de rotas, mantendo o código limpo e organizado.

Diagrama da Arquitetura
